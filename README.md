# 🏢 سيستم مدينتي – لإدارة العقارات والمتابعات (Madinaty Real Estate System)

نظام ويب متكامل وخفيف مصمم للوسطاء العقاريين (السمسار) لإدارة الشقق والعملاء في مدينتي، مع نظام تنبيه ذكي لمواعيد المتابعات، اتصال وواتساب سريع، ومزامنة سحابية لحظية ومجانية بالكامل مع **Google Sheets**.

---

👉 **[https://ayman3tta.github.io/madinaty-system/](https://ayman3tta.github.io/madinaty-system/)**

## ✨ المميزات الرئيسية

- **📂 إدارة وتصنيف الوحدات:**
  - **إيجار (Rent):** تتبع الشقق المتاحة والمحجوزة والمنتهية.
  - **بيع (Sale):** تفاصيل الأسعار الإجمالية والموقف المالي (أقساط / ودائع / عدادات).
  - **مفروش (Furnished):** الشقق المفروشة ومدد الإيجار المتاحة.
  - **عملاء (Clients):** إدارة طلبات العملاء والميزانية ومراحل التفاوض.

- **🚦 نظام ألوان المتابعات الذكي (Follow-up Alerts):**
  - 🔴 **أحمر (فات الميعاد):** إذا مر تاريخ المتابعة ولم يتم التواصل.
  - 🟡 **أصفر/برتقالي (اليوم):** لتنبيهك بالمتابعات المطلوبة خلال اليوم الحالي.
  - 🟢 **أخضر (قادمة):** المتابعات المجدولة في الأيام القادمة.

- **⚡ تواصل سريع بضغطة زر:**
  - 📞 زر اتصال مباشر برقم المالك / العميل.
  - 💬 زر محادثة واتساب يفتح الشات المباشر تلقائياً.

- **☁️ ربط سحابي لحظي ومجاني مع Google Sheets:**
  - كل إضافة، تعديل، أو حذف يتم في الموقع ينعكس فوراً في شيت جوجل أونلاين.
  - يمكن فتح الموقع من أي موبايل أو كمبيوتر ومشاركة البيانات مع فريق العمل.

- **📴 يعمل بدون إنترنت (Offline First):**
  - تخزين محلي تلقائي في المتصفح يضمن فتح النظام بسرعة البرق حتى في حال انقطاع النت.

- **📱 متوافق تماماً مع جميع الشاشات:**
  - تصميم مخصص وسلس للموبايل (Mobile-First) كأنه تطبيق هاتف.
  - دعم الوضع الليلي (Dark Mode) تلقائياً.

## 🚀 كيفية ربط السيستم بـ Google Sheets

السيستم يأتي مجهزاً بملف [`google-apps-script.js`](./google-apps-script.js) الذي يحول أي شيت جوجل إلى قاعدة بيانات متصلة بالنظام مجاناً:

1. افتح [Google Sheets](https://sheets.new) وأنشئ ملفاً جديداً.
2. من القائمة العلوية اضغط على **Extensions (التوسيعات)** ثم **Apps Script**.
3. امسح المحتوى القديم والصق كود ملف [`google-apps-script.js`](./google-apps-script.js) بالكامل، ثم اضغط حفظ 💾.
4. اضغط على زر **Deploy (نشر)** ⬅️ **New deployment (نشر جديد)**.
5. اختر نوع النشر: **Web app (تطبيق ويب)**.
6. اضبط الإعدادات:
   - **Execute as:** `Me` (حسابك).
   - **Who has access:** `Anyone` (أي شخص).
7. اضغط **Deploy** ووافق على أذونات الوصول، ثم انسخ **Web app URL**.
8. افتح السيستم، اضغط على أيقونة الإعدادات **⚙️**، الصق الرابط واضغط **حفظ الرابط** ثم **رفع بيانات السيستم للشيت**.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend:** HTML5, CSS3 (Modern Responsive Flex/Grid), Vanilla JavaScript (No heavy frameworks, Fast & Lightweight).
- **Backend / Database:** Google Apps Script + Google Sheets API (Serverless & Free).
- **Hosting:** GitHub Pages.
- **Offline Storage:** LocalStorage API.
